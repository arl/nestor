# NES Mappers

## What are Mappers?

NES cartridges contain different hardware configurations called "mappers" that allow games to use more memory than the basic NES system provides. Each mapper has a number that identifies its type.

## Currently Supported

Nestor currently supports these mappers:

### Mapper 0: NROM
The simplest mapper with no bank switching. Used by Super Mario Bros. and Donkey Kong.

### Mapper 1: MMC1  
Nintendo's first memory controller. Used by The Legend of Zelda and Metroid.

### Mapper 2: UxROM
Simple banking mapper. Used by Mega Man and Contra.

### Mapper 3: CNROM
Basic graphics banking. Used by Solomon's Key and Arkanoid.

### Mapper 7: AxROM
Single-screen mapper. Used by Battletoads.

### Mapper 66: GxROM
Combined banking mapper. Used by Super Mario Bros. + Duck Hunt.
